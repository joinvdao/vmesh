# Changelog

## Unreleased

- Clarified the top-level product identity: vmesh is both an atlas of antifragility for macro/micro earth intelligence and a source-honest geospatial package broker that protects provenance, confidence, privacy, source roles, and reusable package manifests.
- Fixed the Sentinel/imagery raster attach path so enabling the imagery panel waits for a real MapLibre layer attach instead of reporting active before the source is present.
- Refined `cartesiancs/map3d` research notes as an active MIT React Three Fiber/GLB export reference for OSM-derived buildings, roads, and package-backed visual blockouts for external world-generation conditioning, with explicit Overpass, provenance, and source-truth boundaries.
- Mirrored public-safe downstream source-package research into vmesh docs, including async package-provider boundaries, terrain/global/regional source watchlists, built-environment/capture/graph references, advisory context layers, and a larger open-source repository reference index.
- Added research notes for Kyle Walker's `mapgl` draw-attributes workflow and the Saitama ArcGIS road/river point-cloud atlas, including user-drawn AOI capture, ArcGIS PointCloudLayer preview, download-footprint patterns, CC BY 4.0 source data, CRS, and raw point-cloud sidecar boundaries.
- Expanded the `sacridini/Awesome-Geospatial` research review with a vmesh priority shortlist for open map packages, raster/COG services, STAC/EO processing, terrain/hydrology, climate/environment sources, graph analysis, and source-security tooling.
- Added `Panasonic-Advanced-Technology/q3dweb` as an MIT-licensed point-cloud sidecar reference for LAS/LAZ/E57 inspection, georeferenced map-tile overlays, and fly-through workflows.
- Added global search autocomplete for coordinates, built-in places, and no-key OSM/Nominatim place results, plus close-view Mapterhorn/Mapzen terrain switching.
- Added `maplibre/maplibre-compose` as a BSD-3-Clause Android/Kotlin MapLibre portability reference.
- Added research notes for `INSPIDE/h3j-h3t` and `walkerke/mapboxapi`, including H3 delivery, MapLibre rendering, R geospatial workflow, and Mapbox token-boundary implications.
- Added `hiroaki/Tilia` as a lightweight Leaflet/plugin-runtime reference for static field maps, GPX/photo import, elevation profiles, and local-hub viewer ideas.
- Added Fields of The World as a future agricultural field-boundary source for PMTiles visualization, GeoParquet/PostGIS preprocessing, and H3 food/land intelligence summaries.
- Added `wkentaro/labelme` v6.2.0 as an external annotation workflow reference for human-reviewed imagery labels, oriented rectangles, SAM-assisted draft labels, and privacy-safe fixture generation.
