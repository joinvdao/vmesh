# Open Source Repository References

This file records public GitHub repositories reviewed as research inputs for vmesh. A research reference is not a production dependency or a license approval.

| Repository                  | Category                            | License metadata                                                             | Fork status | vmesh relevance                                                                                                                                                   | Boundary                                                                                                                            |
| --------------------------- | ----------------------------------- | ---------------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `INSPIDE/h3j-h3t`           | H3 delivery / MapLibre rendering    | MIT                                                                          | Not forked  | Compact H3 JSON/tile delivery with client-side geometry generation for MapLibre. Useful reference for H3 as data index rather than always-visible map decoration. | Evaluate before adoption; keep deck.gl path until performance/offline gains are proven.                                             |
| `hiroaki/Tilia`             | Lightweight Leaflet map runtime     | 0BSD                                                                         | Not forked  | Useful reference for no-build embeddable maps, plugin-based layer/UI controls, GPX/photo import, elevation profiles, and static local-hub viewers.                | Leaflet 2 alpha, 2D-only; not a replacement for vmesh's MapLibre globe or terrain stack.                                            |
| `maplibre/maplibre-compose` | Android/Kotlin MapLibre renderer    | BSD-3-Clause                                                                 | Not forked  | Useful future-client reference for rendering interactive vector tile maps in Jetpack Compose while consuming vmesh package manifests.                             | Not a Next.js/web dependency; keep current MapLibre GL JS renderer and treat Compose as a portability target.                       |
| `wkentaro/labelme`          | Image annotation / ML labels        | GPL-3.0                                                                      | Not forked  | Useful external tool for human-in-the-loop annotation of imagery, field boundaries, parcels/features, segmentation masks, and model-training fixtures.            | GPL-licensed desktop/tooling code should not be embedded in the MIT app without license review; use as external workflow reference. |
| `walkerke/mapboxapi`        | R geospatial workflow / Mapbox APIs | GitHub reports `Other`; package license file names year and copyright holder | Not forked  | Useful R workflow reference for geocoding, routing matrices, and vector-tile upload pipelines.                                                                    | Token-gated Mapbox service usage only; not an open-source public default for vmesh.                                                 |
